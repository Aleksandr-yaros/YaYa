# ЯЯ — единый репозиторий проекта

Этот репозиторий является главным источником правды по проекту **ЯЯ**.

## Команда «Где я?»

Когда Александр пишет **«Где я?»**, агент должен:

1. Проверить файл `VERSION.json` в ветке `main`.
2. Показать текущую версию и дату сохранения.
3. Кратко перечислить, что уже зафиксировано.
4. Показать незавершённые блоки и следующий рекомендуемый шаг.
5. Дать ссылки на нужные файлы проекта.

## Структура

- `VERSION.json` — текущая версия проекта.
- `docs/PROJECT_STATE.md` — текущее состояние и архитектура.
- `docs/INDEX.md` — карта всех знаний и заданий.
- `docs/COMMANDS.md` — правила команд для агента.

## Правило сохранения

Каждое существенное изменение проекта должно:

1. Получить новую версию по схеме `MAJOR.MINOR.PATCH`.
2. Быть записано отдельным понятным блоком.
3. Иметь дату, статус, источник решения и следующий шаг.
4. Обновлять `VERSION.json` и `docs/INDEX.md`.

## Текущий статус

Базовая система версионирования и поиска знаний создана.

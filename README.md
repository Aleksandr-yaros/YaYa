# ЯЯ Реестр

Текущая версия: **v4.1.0 Repository Steward+**

`Aleksandr-yaros/YaYa` — управляющий реестр экосистемы ∞ЯЯ.

Он является источником истины для:

- общей архитектуры и стандартов экосистемы;
- карты проектов и репозиториев;
- правил маршрутизации и Commit Boundary;
- паспортов самостоятельных проектов;
- межпроектных ADR, ссылок и безопасных выдержек;
- стандарта хранения фото, рисунков, сканов и схем.

Он **не является единым складом** кода, платежей, договоров, клиентских фото или промптов.

## Короткое обращение

```text
А <действие> <объект>.
```

`А` — короткий алиас `Алибаба`.

Канонические команды записи:

```text
А запомни <материал>.
А запиши <материал>.
```

Примеры:

```text
А запиши это фото в YaKassa.
А запомни этот скан договора.
А запомни этот рисунок Фабрики ботов.
А достань последнее фото по CallCenter.
```

## Фото и рисунки

Медиа хранится в репозитории соответствующего проекта. Базовая структура:

```text
assets/images/source/
assets/images/edited/
assets/images/diagrams/
assets/images/screenshots/
assets/images/scans/
```

Полный стандарт: `docs/MEDIA_STORAGE_STANDARD.md`.

Юридические сканы и оригиналы идут только в private `dogovory`.

## Фабрика ботов

```text
LOGOS·PANDRE → проверка → Commit Boundary → LOGOS·FABRIC
```

Рабочие черновики и эксперименты — `logos-pandre`. Утверждённый канон и релизы — `logos-fabric`.

## Quarantine

Репозитории `Dogovora`, `Pesochnica`, `-gpt`, `-1`, `-`, `-2` не участвуют в автоматической маршрутизации до отдельного решения.

## Команда «Где я?»

Когда Александр пишет `Где я?`, агент должен:

1. проверить `VERSION.json` в `main`;
2. показать текущую версию и дату сохранения;
3. перечислить проекты и репозитории;
4. показать незавершённые блоки и риски;
5. дать источники истины;
6. назвать один лучший следующий шаг.

## Главные файлы

- `VERSION.json` — версия и машинный реестр;
- `docs/INDEX.md` — индекс знаний;
- `docs/REPOSITORY_CATALOG.md` — карта проектов и всех классифицированных репозиториев;
- `docs/MEDIA_STORAGE_STANDARD.md` — фото, рисунки, сканы и схемы;
- `docs/ALIBABA_ROUTER_PROTOCOL.md` — протокол обращения и маршрутизации;
- `docs/COMMANDS.md` — команды агента;
- `CHANGELOG.md` — история апгрейдов.

## Правило сохранения

Каждое существенное изменение должно иметь один источник истины, версию, статус, владельца, C/E для C2–C4, Commit Boundary, commit SHA и план отката.

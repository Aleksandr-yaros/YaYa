# Команды агента Яя

Версия команд: **5.0.0**  
Версия реестра: **4.0.0 Alibaba Universal Router**

## 1. Общая команда

```text
Яя, <канонический контур>: <НАМЕРЕНИЕ> <задание>.
```

Контуры:

- `ЯЯ Реестр`;
- `ЯЯ Оплата`;
- `Фабрика ботов ЯЯ`;
- `Договоры Ярос`;
- `YaKassa·WORKSPACE`.

## 2. Фабрика ботов ЯЯ

Каноническая форма:

```text
Яя, Фабрика ботов ЯЯ: <НАМЕРЕНИЕ> <задание>.
```

Намерения:

- `ДОСТАНЬ`;
- `СТАТУС`;
- `ПРОАНАЛИЗИРУЙ`;
- `СПРОЕКТИРУЙ`;
- `СОЗДАЙ`;
- `ПРОВЕРЬ`;
- `СОХРАНИ`;
- `ВЫПУСТИ`;
- `УЛУЧШИ`;
- `ОСТАНОВИ`;
- `АРХИВИРУЙ`.

### Достать обращение

```text
Яя, Фабрика ботов ЯЯ: ДОСТАНЬ ОБРАЩЕНИЕ.
```

```text
Яя, ЯЯ Реестр: ДОСТАНЬ ОБРАЩЕНИЕ «Фабрика ботов ЯЯ».
```

```text
Яя, база номер два: ДОСТАНЬ ОБРАЩЕНИЕ.
```

Источник: `docs/YAYA_BOT_FACTORY_ACCESS_CARD.md`.

### Лучший повседневный запрос

```text
Яя, Фабрика ботов ЯЯ: СОЗДАЙ <электронного сотрудника> для <измеримой бизнес-цели>.
Пользователи: <кто>.
Канал: <где>.
Интеграции: <системы>.
Разрешено: <действия>.
Запрещено: <действия>.
Критерий готовности: <проверяемый результат>.
```

### Промышленный запрос

```text
Яя, Фабрика ботов ЯЯ: СОЗДАЙ <объект> как производственный заказ. Примени LEXA, ORLIKIN·SPIDER 8/8, SPEC, SPEC·GUARD, IMPACT и Salim/SLM. Установи C/E, проведи dry-run, покажи риск, стоимость владения, наблюдаемость и откат. До записи покажи Commit Boundary. После подтверждения сохрани, проверь и верни версию, пути и commit SHA.
```

## 3. Автоматическое усиление

Короткий запрос автоматически нормализуется в структуру:

`намерение → объект → бизнес-результат → пользователи → канал → данные → права → интеграции → критерии → C/E → риск → откат → Commit Boundary`.

Предположения помечаются. Для C2–C4 критические предположения не утверждаются молча.

## 4. Обязанности агента

1. Определить контур и намерение.
2. Проверить владельца жизненного цикла и источник истины.
3. Проверить видимость и доступность репозитория.
4. Для C2–C4 указать C/E.
5. Показать риск, откат и Commit Boundary.
6. Если репозиторий отсутствует — применить `BLOCKED_BY_REPOSITORY`.
7. После записи вернуть контур, намерение, путь, версию, commit SHA и проверку.

## 5. «Где я?»

Открыть `VERSION.json` и показать версию, кодовое имя, контуры, последние изменения, блокировки, риски и следующий шаг.

## 6. «Сохрани версию»

Определить контур, обновить тематический файл, `VERSION.json`, `docs/INDEX.md` и `CHANGELOG.md`, провести routing tests и вернуть доказательство.

## 7. «Усиль по Salim на 10»

Применить:

`SLM = (B × C × E) × V × ΔM × L × R × T × A`

`ΔM > 1` допустим только при `C ≥ 2` и `E ≥ 2`.

## 8. Источник истины

Приоритет:

1. `VERSION.json`;
2. `docs/YAYA_BOT_FACTORY_ACCESS_CARD.md` для обращений Фабрики;
3. `docs/YAYA_BOT_FACTORY_MASTER_COMMAND.md`;
4. `docs/INDEX.md`;
5. этот файл.

## 9. Запрет молчаливых записей

Существенная запись выполняется только после явного Commit Boundary. Прямая команда «всё запиши» считается разрешением на описанный апгрейд после определения контуров, файлов, риска и отката.

## 10. «Привет, Алибаба» — рабочая память

Общая команда:

```text
Привет, Алибаба, покажи рабочие архивы.
```

YaKassa:

```text
Привет, Алибаба, YaKassa: ПОКАЖИ АРХИВ.
Привет, Алибаба, достань информацию по YaKassa: <тема>.
Привет, Алибаба, сохрани в YaKassa: <материал>.
Привет, Алибаба, YaKassa: ПОКАЖИ ПОСЛЕДНИЕ ВЕРСИИ.
```

Если назван только продукт, показать категории, количество материалов, последние версии и один лучший следующий запрос. Для `ДОСТАНЬ` вернуть материал, путь, версию, дату и источник. Для `СОХРАНИ` определить категорию, имя, чувствительность, версию и Commit Boundary; молчаливые записи запрещены.


## 11. ALIBABA·ROUTER v2.0.0

### Самая короткая форма

```text
Алибаба, <что сделать> <с чем>.
```

Примеры:

```text
Алибаба, сохрани это.
Алибаба, достань последнее КП.
Алибаба, покажи, что есть по YaKassa.
Алибаба, улучши это на 10 без записи.
Алибаба, сравни с предыдущей версией.
```

### Точная форма

```text
Алибаба, <ДЕЙСТВИЕ> <ОБЪЕКТ>.
Контур: <проект или продукт>.
Режим: <без записи / черновик / чистовик>.
Критерий: <что считать готовым>.
```

### Обучение

```text
Алибаба, научи меня правильно обратиться: <цель>.
```

Вернуть исправленную команду, объяснение, короткую и точную форму и один лучший вариант.

### Приземление

```text
Алибаба, приземли: <идея>.
```

Вернуть факт, предположение, недостающие данные, C/E, практический эффект, риск и один следующий шаг.

### Обязательный ответ после записи

`что понял → куда записал → путь → версия → commit SHA → проверка → как достать → следующий шаг`.

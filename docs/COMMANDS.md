# Команды агента Яя

Версия команд: **6.0.0**  
Версия реестра: **4.1.0 Repository Steward+**

## 1. Самая короткая команда

```text
А <действие> <объект>.
```

`А` — постоянный короткий алиас `Алибаба`.

Канонические команды записи:

```text
А запомни <материал>.
А запиши <материал>.
```

Обе означают явное намерение `СОХРАНИ`. Агент сам определяет проект, репозиторий, категорию, путь, приватность и версию. Для C2–C4 сохраняются C/E, риск, откат и Commit Boundary.

## 2. Универсальная команда

```text
Алибаба, <что сделать> <с чем> [для кого/где/как].
```

или

```text
Яя, <канонический контур>: <НАМЕРЕНИЕ> <задание>.
```

## 3. Канонические контуры

- `ЯЯ Реестр` → `Aleksandr-yaros/YaYa`;
- `Договоры Ярос` → `Aleksandr-yaros/dogovory`;
- `Фабрика ботов ЯЯ · черновик` → `Aleksandr-yaros/logos-pandre`;
- `Фабрика ботов ЯЯ · чистовик` → `Aleksandr-yaros/logos-fabric`;
- `YaKassa·WORKSPACE` → `Aleksandr-yaros/YaKassa-Workspace`;
- `CallCenter` → `Aleksandr-yaros/CallCenter` с обязательной privacy-проверкой;
- `ЯЯ Оплата` → целевой private `Aleksandr-yaros/YaYa-Pay` после создания.

Полный каталог: `docs/REPOSITORY_CATALOG.md`.

## 4. Ключевые слова

- `договор`, `акт`, `допсоглашение`, `юридический оригинал`, `скан договора` → Договоры Ярос;
- `фабрика ботов`, `электронный сотрудник`, `бот`, `промпт`, `роль`, `SPEC`, `LEXA`, `ORLIKIN`, `SPIDER` → Фабрика ботов;
- `YaKassa`, `Якасса`, `КП YaKassa` → YaKassa·WORKSPACE;
- `CallCenter`, `колл-центр`, `контакт-центр` → CallCenter;
- `QR`, `ePOS`, `платёж`, `возврат`, `чек`, `баллы ЯЯ` → ЯЯ Оплата;
- `архитектура`, `правило`, `канон`, `маршрутизация`, `карта проектов`, `версия` → ЯЯ Реестр.

Слово `документ` без контекста не означает автоматически договор. Сначала определяется проект и смысл.

## 5. Фото, рисунки и сканы

Стандарт: `docs/MEDIA_STORAGE_STANDARD.md`.

Короткие команды:

```text
А запиши это фото в YaKassa.
А запомни этот рисунок Фабрики ботов.
А запиши этот скан договора.
А достань последнее фото по CallCenter.
```

Проектные медиа хранятся в проектном репозитории, обычно:

```text
assets/images/source/
assets/images/edited/
assets/images/diagrams/
assets/images/screenshots/
assets/images/scans/
```

Юридические оригиналы и сканы → private `dogovory`.

## 6. Фабрика ботов ЯЯ

Рабочий цикл:

```text
LOGOS·PANDRE → LEXA → ORLIKIN·SPIDER → SPEC → SPEC·GUARD → Test → IMPACT → dry-run → Commit Boundary → LOGOS·FABRIC → Release → Observability / Rollback
```

Черновое и экспериментальное → `logos-pandre`.
Утверждённое после проверки → `logos-fabric`.

## 7. Автоматическое усиление

Короткий запрос нормализуется в:

`намерение → объект → проект → бизнес-результат → данные → права → интеграции → критерии → C/E → риск → откат → Commit Boundary`.

## 8. «Где я?»

Открыть `VERSION.json` и показать версию, кодовое имя, проекты, репозитории, последние изменения, блокировки, риски и один следующий шаг.

## 9. «Сохрани версию»

Определить контур, обновить тематический файл, `VERSION.json`, `docs/INDEX.md` и `CHANGELOG.md`, провести routing checks и вернуть доказательство.

## 10. «На 10» / Salim

```text
А на 10 <задача>.
А усиль по Salim на 10 <объект>.
```

Формула:

`SLM = (B × C × E) × V × ΔM × L × R × T × A`

Для C2–C4 фиксировать C/E. `ΔM > 1` допустим только при `C ≥ 2` и `E ≥ 2`.

## 11. Репозитории quarantine

Автоматическая запись запрещена в:

- `Aleksandr-yaros/Dogovora`;
- `Aleksandr-yaros/Pesochnica`;
- `Aleksandr-yaros/-gpt`;
- `Aleksandr-yaros/-1`;
- `Aleksandr-yaros/-`;
- `Aleksandr-yaros/-2`.

Они имеют статус `UNCLASSIFIED / QUARANTINE` до отдельного решения.

## 12. Контракт после записи

`что понял → проект → репозиторий → путь → версия → commit SHA → C/E при необходимости → проверка → как достать → следующий шаг`.

## 13. Безопасность

- молчаливые записи запрещены;
- `А запомни` и `А запиши` — явное намерение записи, но не обход контроля;
- private-материалы не копируются в public;
- секреты, ключи и пароли не сохраняются;
- отправка, публикация и удаление требуют отдельного подтверждения;
- один оригинал — один источник истины.

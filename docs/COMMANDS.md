# Команды агента Яя

Версия команд: **2.0.0**  
Версия реестра: **2.5.0 Routing Integrity**

## 1. Основная команда

```text
Яя, <канонический контур>: <задание>
```

Канонические контуры:

- `ЯЯ Реестр`;
- `ЯЯ Оплата`;
- `Фабрика ботов ЯЯ`;
- `Договоры Ярос`.

Примеры:

```text
Яя, ЯЯ Реестр: обнови карту проектов.
```

```text
Яя, ЯЯ Оплата: проверь сценарий возврата.
```

```text
Яя, Фабрика ботов ЯЯ: создай паспорт электронного продавца.
```

```text
Яя, Договоры Ярос: предложи путь для договора.
```

## 2. Правило вызова

Вызовом агента считаются:

- `Яя,`;
- `Яя:`;
- `Привет, Яя.`;
- голосовая форма `я, я` в начале команды.

Форма `ЯЯ:` не является надёжным вызовом агента и не разрешает запись без уточнения контура.

## 3. Обязанности агента

1. Определить объект, контур и владельца жизненного цикла.
2. Проверить чувствительность, доступность и видимость репозитория.
3. Назвать единственный источник истины и точный путь.
4. Для C2–C4 явно указать C и E.
5. Проверить конфликт между указанным контуром и содержанием.
6. Если репозиторий отсутствует — присвоить `BLOCKED_BY_REPOSITORY`, не складывать рабочий оригинал в `YaYa`.
7. До записи показать риск, откат и Commit Boundary.
8. После записи вернуть контур, репозиторий, путь, версию, commit SHA и результат проверки.

## 4. «Где я?»

Агент обязан открыть `VERSION.json` и показать:

- версию и кодовое имя;
- дату сохранения;
- четыре канонических контура;
- последние изменения;
- незавершённые репозитории;
- риски;
- один лучший следующий шаг.

## 5. «Сохрани версию»

Агент должен:

1. определить правильный контур;
2. проверить источник истины;
3. присвоить новую версию;
4. обновить тематический файл, `VERSION.json`, `docs/INDEX.md` и `CHANGELOG.md`;
5. провести routing tests;
6. вернуть доказательство сохранения.

## 6. «Усиль по Salim на 10»

Применить:

`SLM = (B × C × E) × V × ΔM × L × R × T × A`

Показать:

- B — бизнес-пользу;
- C — воздействие;
- E — доказательность;
- V — скорость ценности;
- ΔM — дополнительную ценность;
- L — жизненный цикл;
- R — устойчивость;
- T — стоимость владения;
- A — ответственность/Аманат.

`ΔM > 1` допустим только при `C ≥ 2` и `E ≥ 2`.

## 7. «Проверь маршрутизацию»

Агент проверяет минимум:

- стандарт → `ЯЯ Реестр`;
- QR, платёж, чек, возврат, баллы → `ЯЯ Оплата`;
- бот, промпт, роль, электронный сотрудник → `Фабрика ботов ЯЯ`;
- договор, акт, допсоглашение → `Договоры Ярос`;
- неоднозначное `ЯЯ:` → запись запрещена;
- отсутствующий репозиторий → `BLOCKED_BY_REPOSITORY`.

## 8. Источник правды

GitHub `main` является источником истины. При расхождении памяти и репозитория приоритет имеют:

1. `VERSION.json`;
2. `docs/YAYA_NAMESPACE_CANON.md`;
3. `docs/YAYA_ROUTING_INTEGRITY_AUDIT.md`;
4. `docs/YAYA_REPOSITORY_ROUTER.md`;
5. этот файл.

## 9. Запрет молчаливых записей

Существенная запись выполняется только после явного Commit Boundary. Прямая команда пользователя «сделай апгрейд и сохрани» считается разрешением на конкретно описанный апгрейд, если контур, файлы, риски и откат определены.

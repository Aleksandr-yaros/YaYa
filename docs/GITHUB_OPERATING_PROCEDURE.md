# ЯЯ · GitHub Operating Procedure

Версия: **1.0.0**
Статус: **approved**
Дата: **2026-08-08**
Класс: **C3 / E4**

## Два действия записи

`А запомни ...` — сделать информацию постоянной версионируемой памятью проекта: правило, решение, архитектурный вывод, утверждённый факт или повторно используемое знание.

`А запиши ...` — сохранить конкретный артефакт: текст, документ, фото, рисунок, схему, скриншот, скан, таблицу или исходник.

## Текущий проект

После однозначного определения проекта он становится `CURRENT_PROJECT` для последующих коротких команд в текущем рабочем контексте.

Слова `там`, `туда`, `сюда`, `в этот проект`, `здесь` относятся только к последнему однозначно определённому проекту. Они не означают случайный последний репозиторий GitHub.

Пример:

```text
А покажи YaKassa.
А запомни это там.
```

Вторая команда наследует проект YaKassa.

## Обязательные шаги

1. Определить действие.
2. Определить объект.
3. Определить проект: явно названный проект → CURRENT_PROJECT → ключевые слова → владелец жизненного цикла.
4. Сверить репозиторий с `docs/REPOSITORY_CATALOG.md`.
5. Проверить приватность и допустимость хранения.
6. Определить категорию и путь.
7. Нормализовать имя и версию.
8. Для C2–C4 зафиксировать C/E; при `НА 10` применить Salim/SLM.
9. Проверить Commit Boundary, риск и откат.
10. Записать только в источник истины проекта.
11. После записи повторно проверить проект, репозиторий, путь, версию и видимость.
12. Вернуть доказательство: проект → репозиторий → путь → версия → commit SHA → проверка → команда извлечения → один следующий шаг.

## Граница разрешения

`А запомни ...` и `А запиши ...` являются явным разрешением на описанную запись после безопасной маршрутизации. Они не означают разрешение на публикацию, удаление или отправку третьим лицам.

## Ошибки, которые надо предотвращать

- договор в public-репозитории вместо private `dogovory`;
- черновик Фабрики сразу в `logos-fabric`;
- чувствительный материал CallCenter в public;
- платёжный оригинал в `YaYa` вместо целевого платёжного контура;
- дублирование одного оригинала в нескольких проектах;
- автоматическая запись в quarantine;
- потеря CURRENT_PROJECT при словах `там` и `туда`;
- перезапись утверждённого оригинала без версии;
- сообщение об успешной записи без commit SHA.

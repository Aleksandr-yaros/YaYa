| ID | Раздел | Статус | Файл |
|---|---|---|---|

## Как искать

- `Где я?` — показать текущую версию и статус.
- `AIA: ДОСТАНЬ YAYA-AIA` — достать протокол AIA.
- `AIA: ЭВОЛЮЦИЯ YAYA-AIA` — показать историю улучшений.
- `AIA: СОХРАНИ` — создать новый блок знаний.
- `AIA: АПГРЕЙД` — обновить существующий блок и версию.

## Правило индекса

Каждая важная тема получает постоянный ID, статус, отдельный файл и запись в истории версий.

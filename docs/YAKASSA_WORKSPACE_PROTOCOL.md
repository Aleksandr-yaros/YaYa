# YaKassa·WORKSPACE — протокол рабочей памяти

Версия: **1.0.0**  
Статус: **approved / repository creation pending**  
Целевой источник истины: private `Aleksandr-yaros/YaKassa-Workspace`

## Назначение

Приватно хранить, версионировать и быстро извлекать повседневные рабочие материалы YaKassa. Публичный реестр хранит только этот маршрут и не содержит клиентских данных, коммерческих условий или самих рабочих файлов.

## Рекомендуемая структура private-репозитория

- `00_INBOX` — новые неразобранные материалы;
- `01_COMMERCIAL_OFFERS` — коммерческие предложения;
- `02_PHOTOS_MEDIA` — фотографии, логотипы, макеты и скриншоты;
- `03_TEMPLATES` — повторно используемые формы;
- `04_PRICES_TARIFFS` — актуальные коммерческие условия;
- `05_CLIENTS_PROJECTS` — материалы проектов;
- `06_PRODUCT_FACTS` — проверенные характеристики и источники;
- `07_ROUTINE_OPERATIONS` — инструкции и чек-листы;
- `08_ARCHIVE` — заменённые и закрытые версии;
- `MANIFEST.md` — понятный человеку каталог;
- `INDEX.json` — машинный индекс.

## Команды

```text
Привет, Алибаба, покажи рабочие архивы.
Привет, Алибаба, YaKassa: ПОКАЖИ АРХИВ.
Привет, Алибаба, достань информацию по YaKassa: <тема>.
Привет, Алибаба, сохрани в YaKassa: <материал>.
Привет, Алибаба, YaKassa: ПОКАЖИ ПОСЛЕДНИЕ ВЕРСИИ.
```

## Контракт ответа

- `ПОКАЖИ АРХИВ`: категории, количество материалов, последние версии, открытые задачи и лучший следующий запрос.
- `ДОСТАНЬ`: лучший результат, путь, версия, дата, статус и связанные материалы.
- `СОХРАНИ`: категория, нормализованное имя, чувствительность, версия, Commit Boundary и commit SHA.
- При неоднозначности задать один короткий уточняющий вопрос.
- Молчаливые записи запрещены.

## Именование

`YYYY-MM-DD__TYPE__SUBJECT__vMAJOR.MINOR.PATCH.ext`

Каждая запись индексируется по названию, категории, дате, версии, статусу, источнику, связанным файлам, чувствительности и следующему шагу.

## Безопасность

- рабочий репозиторий только private;
- секреты, пароли и ключи не сохраняются;
- персональные данные минимизируются;
- публичный `YaYa` хранит только безопасный маршрут;
- публикация и удаление требуют отдельного подтверждения.

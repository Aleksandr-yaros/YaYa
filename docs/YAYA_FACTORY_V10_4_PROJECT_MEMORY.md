## 3. Единый дух

> **Ответственное усиление.** Цифровой сотрудник видит, помогает, создаёт, защищает, выращивает, управляет и советует, но каждое значимое действие имеет человека-владельца, стоимость, Evidence и возможность отката.

Краткая формула:

```text
Понимание
→ польза
→ результат
→ защита
→ рост
→ управление
→ мудрый следующий шаг
```

## 4. Что представляет собой проект

ЯЯ·ФАБРИКА — self-hosted платформа компании «Ярос» для создания и управления цифровыми сотрудниками.

Цифровой сотрудник — это не отдельный чат-бот. Он имеет:

- имя, должность и владельца-человека;
- функции и каналы;
- права и запреты;
- KPI и AI-бюджет;
- версию и уровень Evolution 7×7;
- Evidence каждого действия;
- IMPACT и полную стоимость;
- rollback-профиль.

## 5. Технологический канон

```text
Laravel Control Plane
+ LOGOS_ЦЕНТР · 1С 8.3
+ Python AI/STT Runtime
+ Function Bus
+ подключаемые адаптеры
+ Evidence Ledger
+ AI Usage & Billing
+ IMPACT / SLM
```

Распределение ответственности:

- **PHP + Laravel** — основной прикладной стек Саши: web-интерфейс, API, Tenant, очереди, BotSpec Draft, read-модели и адаптеры.
- **1С:Предприятие 8.3** — бизнес-объекты, документы, подтверждения, Commit Boundary, Evidence, IMPACT и закрытие биллинга.
- **Python** — STT и AI-вычисления без права самостоятельной продуктивной записи.

## 8. Граница демонстрации

Все HTML-прототипы работают только на синтетических данных.

```text
productionWrite = false
realSip = false
realBilling = false
externalWrite = false
```

Они не являются поставкой `.cf`, `.cfe`, `.dt` или промышленным Laravel-приложением.

## 10. Неподвижные правила

- Компания называется только **«Ярос»**.
- AI не имеет права самостоятельной продуктивной записи.
- Роли Evolution не расширяют RBAC автоматически.
- Для C2–C4 обязательны SPEC·GUARD, IMPACT, dry-run, подтверждение, Commit Boundary, Evidence и rollback.
- Секреты хранятся в защищённом хранилище и показываются masked.
- Демо не подключается к живым данным без отдельного решения.
- Никаких молчаливых изменений действующего бота.
- SLM-10 является целью зрелости, а не доказанным фактом до пилота E4.

# ЯЯ — постоянная команда маршрутизации

Статус: **approved permanent canon**  
Версия документа: **2.0.0**  
Версия реестра: **2.5.0 Routing Integrity**  
Дата: **2026-08-06**  
Владелец: **Александр / Ярос**

## Постоянное правило

Когда Александр обращается к агенту формой `Яя,`, `Яя:`, `Привет, Яя.` или голосовой формой `я, я` в начале команды, агент обязан определить канонический контур, источник истины, чувствительность и маршрут.

Форма `ЯЯ:` сама по себе больше не считается надёжным вызовом агента и не разрешает запись.

## Каноническая полная команда

```text
Яя, <канонический контур>: <задание>
```

Канонические контуры:

- `ЯЯ Реестр`;
- `ЯЯ Оплата`;
- `Фабрика ботов ЯЯ`;
- `Договоры Ярос`.

## Обязательный цикл

```text
Вызов Яя
→ определение канонического контура
→ проверка конфликта между адресом и содержанием
→ классификация чувствительности
→ выбор одного источника истины
→ проверка существования, доступа и видимости репозитория
→ выбор пути и версии
→ Salim/SLM и C/E
→ риск и откат
→ Commit Boundary
→ запись
→ routing tests
→ доказательство: контур, репозиторий, путь, версия, commit SHA
```

## Карта маршрутизации

- архитектура экосистемы, стандарты, реестр, паспорта и ADR → `Aleksandr-yaros/YaYa`;
- QR, платежи, ePOS, чеки, возвраты, сверка и баллы → целевой приватный `Aleksandr-yaros/YaYa-Pay`;
- боты, промпты, роли, код, тесты и электронные сотрудники → целевой приватный `Aleksandr-yaros/YaYa-Bot-Factory`;
- договоры, приложения, соглашения и акты → приватный `Aleksandr-yaros/dogovory`.

## Недоступный целевой репозиторий

Если `YaYa-Pay` или `YaYa-Bot-Factory` ещё не создан или недоступен:

- рабочий оригинал не сохранять в `YaYa`;
- статус маршрута установить `BLOCKED_BY_REPOSITORY`;
- в `YaYa` допускаются только паспорт, ADR, план миграции и ссылка;
- показать следующий Commit Boundary для создания или подключения репозитория.

## Неоднозначность

- `ЯЯ` без уточнения не определяет место записи.
- Алиас `Проект ЯЯ` является устаревающим и означает `ЯЯ Оплата` только при явном контексте платежей, QR, ePOS, чеков, возвратов или баллов.
- Если явно указанный контур конфликтует с содержанием, агент обязан остановить запись и показать правильный маршрут.

## Один оригинал — один источник истины

Нельзя копировать один рабочий оригинал в несколько репозиториев. В других контурах допускаются только ссылка, ID, версия интерфейса, тест совместимости, ADR или безопасная выдержка.

## Commit Boundary

Перед записью показать:

```text
Вызов: Яя
Канонический контур: ...
Источник истины: ...
Репозиторий существует: да/нет
Видимость: ...
Путь: ...
C/E: ...
Действия: ...
Главный риск: ...
Откат: ...
Commit Boundary: ожидается/разрешён
```

Молчаливые записи, удаления, переименования и публикации запрещены.

## Salim/SLM на 10

`SLM = (B × C × E) × V × ΔM × L × R × T × A`

Для C2–C4 обязательно зафиксировать C и E. `ΔM > 1` допустим только при `C ≥ 2` и `E ≥ 2`.

Усиление должно охватывать пользу, доказательность, скорость ценности, дополнительную ценность, полный жизненный цикл, устойчивость, стоимость владения и ответственность/Аманат.

## Голосовая команда

```text
Яя, определи канонический контур для того, что я передаю. Проверь, относится ли это к ЯЯ Реестру, ЯЯ Оплате, Фабрике ботов ЯЯ или Договорам Ярос. Покажи один источник истины, репозиторий, путь, C/E, риск и откат. Если репозиторий не создан, не складывай рабочий материал в реестр. Ничего существенно не записывай без Commit Boundary. После разрешения сохрани, проверь маршрутизацию и верни commit SHA.
```

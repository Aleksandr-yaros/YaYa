Версионируемый цифровой участник организации, имеющий должность, руководителя-человека, обязанности, KPI, рабочий график, разрешённые данные, функции, интеграции, запреты, лимиты, уровень самостоятельности, владельца ответственности и сценарий отката.

CHIEF SERVER
Шеф видит все организации, подписки, цифровых сотрудников, владельцев, версии, права, интеграции, стоимость, эффект, риски и инциденты. Он создаёт сотрудников визуально, шаблоном, текстом или голосом на компьютере. Голос создаёт проект изменения, но не выполняет критическую запись без Commit Boundary.

КАБИНЕТ ОРГАНИЗАЦИИ
Каждая организация-подписчик получает отдельный Tenant: собственных пользователей, логины, роли, цифровых сотрудников, интеграции, лимиты, действия, доказательства и отчёты. Организация видит только свой контур. Межтенантный доступ запрещён.

АУТЕНТИФИКАЦИЯ
Логин и стойко хешированный пароль; пароль никогда не хранится открытым текстом. Для администраторов обязательна MFA. Для крупных клиентов возможны SSO и выделенный private-контур.

ПРАВА
RBAC определяет роль пользователя. ABAC учитывает организацию, подразделение, проект, тип данных, сумму, время, устройство, риск, владельца процесса и наличие подтверждения. Действует принцип минимальных полномочий. Цифровой сотрудник не может расширить свои права самостоятельно.

РОЛИ

AI не самоуполномочивается. Любое существенное изменение проходит Gatekeeper → Policy Engine → проверку RBAC/ABAC → C/E → dry-run → visual diff → подтверждение → Commit Boundary → версию → аудит → IMPACT. Все действия имеют доказательства. Есть остановка и rollback.

ИТОГ
Шеф управляет цифровой рабочей силой из одного окна. Организации покупают подписку и управляют только своим цифровым штатом. Каждый цифровой сотрудник переносим между отделами и интеграциями, но всегда действует в пределах паспорта, прав, политики, ответственности и доказательств.

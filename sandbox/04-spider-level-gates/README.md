# SPIDER / ПАУК УРОВНЕЙ — YAYA Sandbox

Статус: CANDIDATE

## Зачем
SPIDER запрещает принимать уровень разработки по словам «почти готово». Уровень существует только если команда доказала уникальные способности этого уровня и прошла анти-тесты, отличающие его от соседних уровней.

## Как обращаться
Команда вызова: **«Паук, покажи уровень N»**.
Допустимо: **«Паук, проверь команду на L4»**, **«Паук, анти-САЛЫМ L5»**, **«Паук, чем L7 отличается от L9?»**.

## Формула уровня
LEVEL = CAPABILITY + DIFFERENCE + TEST + EVIDENCE + READ-BACK + GATE

Уровень НЕ считается достигнутым, если отсутствует хотя бы одно звено.

## 6 ног Паука
1. **Смысл** — что новый уровень умеет, чего прошлый не умеет.
2. **Физика** — что реально происходит в системе/на устройстве.
3. **Психология** — что по-другому видит и делает человек.
4. **Инженерия** — какой новый контракт/объект/алгоритм существует.
5. **Доказательство** — тест, лог, screenshot, запись, API-result.
6. **Анти-САЛЫМ** — тесты, которые специально пытаются доказать, что уровень заявлен ложно.

## Gate
Для каждого Lx:
- 3–4 уникальных PASS-теста;
- минимум 1 NEGATIVE/ANTI-тест;
- отличие от L(x-1);
- запрет на способность L(x+1), если она ещё не доказана;
- Evidence Pack;
- независимый read-back тестировщика;
- Acceptance Owner.

## Игровой режим
Каждый уровень = «комната».
Команда получает 3–4 мини-миссии.
За миссию выдаётся только PASS/FAIL, не проценты «почти».
Открытие следующей комнаты происходит только после 100% обязательных миссий и 0 критических anti-SALYM ошибок.

## Визуальное правило
Каждый уровень обязан иметь один контрольный экран/схему:
BEFORE L(x-1) → CURRENT Lx → FORBIDDEN CLAIM L(x+1)

Владелец должен отличить соседние уровни визуально за 10 секунд.

## Handoff
SOURCE -> READ-BACK -> CONFIRM -> FREEZE.
Если read-back не подтверждён: HANDOFF NOT COMPLETE.

## Error Breadcrumb
Любая ошибка/ложное заявление/потеря контекста фиксируется:
GAP -> EVIDENCE -> RECOVERY -> PREVENTION.

## Главное правило
**«Почти L5» = L4.**
Пока последний обязательный тест L5 не пройден, статус остаётся L4.
